Description du programme : 

Petit programme Java de gestion d'inventaire, composé de deux classes :

Panier : additionne des prix hors taxes et calcule le total toutes taxes comprises ;
Stock : enregistre les entrées et les sorties d'articles, et refuse une sortie supérieure à la quantité disponible.



Configuration : 

Copier .env.example en .env, puis renseigner les valeurs.
Le fichier .env est ignoré par Git et ne doit jamais être commité.
